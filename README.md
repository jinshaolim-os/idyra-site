# idyra.ai

The built static site for https://idyra.ai, published with GitHub Pages.

This repository holds **only the built output**. It is generated from `website/` in a private source repository by
`node website/build.mjs`, which checks every page (labels, claims, links, a leak scan) before writing. Don't edit files
here by hand; rebuild and republish instead.

Idyra is not an estate agent. Visuals are labelled: Measured, Rendered from building-plan drawings, or AI-illustrative.
Models are not as-built and not a survey. No drawings are published here.
