IDYRA COURTYARD HOUSE — ORIGINAL FICTIONAL CONCEPT

Authored geometry, procedural textures, SVG plan and configuration data are original Idyra demonstration work. No client drawings, property records, stock models, external texture photographs or generated images are used. Not client work; not construction-ready design.

Runtime dependency: Three.js 0.186.0, including OrbitControls, RoomEnvironment, RoundedBoxGeometry and BufferGeometryUtils. Bundled from the existing local installation; no CDN requests.
Build dependency: esbuild 0.28.2 (not shipped in the runtime).
Type: system fonts; no external font assets.
